# MicroStep AI

**Опублікований сайт:** https://LOGIN.github.io/

MicroStep AI — вебзастосунок, який допомагає подолати прокрастинацію: ви вводите справу, обираєте рівень опору, а застосунок розбиває її на маленькі, реалістичні мікро-кроки з таймерами та підтримкою.

## Головні функції

- **Розбиття справи на мікро-кроки** з урахуванням рівня опору: легкий ступор, важко почати, панічний страх.
- **Генерація кроків через AI (OpenRouter)** за наявності API-ключа та **локальний fallback (mock)** без ключа або при помилці AI.
- **Таймери для кроків**: старт/пауза/скидання, збереження стану.
- **Керування кроками**: позначити виконаним, редагувати, додати, видалити, змінити порядок.
- **Адаптація кроків**: «Завеликий», «Мало часу», «Не виходить» (з причиною) — спрощення/подрібнення кроку.
- **Прогрес і завершення сесії**: прогрес-бар, конфеті/звукові сигнали, підсумок виконання.
- **Збереження прогресу** в браузері (`localStorage`): відновлення незавершеної сесії після перезавантаження.
- **Історія та стрік**: завершені справи, статистика, активність за останні дні.
- **Налаштування**: OpenRouter API key і вибір моделі.

## Локальний запуск

```bash
npm install
npm run dev
npm run build
```

- `npm install` — встановлення залежностей.
- `npm run dev` — запуск локального dev-сервера (Vite).
- `npm run build` — збірка проєкту для продакшену.
